📦 Extracción H5P

Esta utilidad te permite extraer y reconstruir la hoja de cálculo original a partir de cualquier actividad **H5P InfoWall** (.h5p) o archivo de datos **content.json**.

El descompilador analizará las propiedades del catálogo H5P y las convertirá en las columnas de una nueva hoja de cálculo, extrayendo incluso los enlaces directos (URLs) incrustados en las descripciones.

Nota de uso: Esta aplicación procesa el inventario 100% de forma local. Genera archivos ZIP de contenido o empaquetados .h5p válidos con las dependencias de InfoWall v0.4 preconfiguradas.
